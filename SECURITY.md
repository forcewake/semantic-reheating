# Security policy

## Supported versions

Security fixes are applied to the latest development release of this reference kit.

## Reporting a vulnerability

Please do not include sensitive traces, credentials, private transcripts, or exploit details in public issues. Report suspected vulnerabilities through the [GitHub private vulnerability-reporting form](https://github.com/forcewake/semantic-reheating/security/advisories/new), with a minimal synthetic reproduction and the affected version when available.

If private reporting is unavailable, [open a public GitHub issue requesting a secure reporting path](https://github.com/forcewake/semantic-reheating/issues/new/choose). Include only a high-level request; do not disclose vulnerability details or sensitive material.
