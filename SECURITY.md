# Security policy

## Supported versions

Security fixes are applied to the latest development release of this reference kit.

## Reporting a vulnerability

Please do not include sensitive traces, credentials, private transcripts, or exploit details in public issues. Report a suspected vulnerability privately through the repository maintainer contact channel, with a minimal synthetic reproduction and the affected version when available.

If no private contact channel is available, open a public issue containing only a high-level request for a secure reporting path.
